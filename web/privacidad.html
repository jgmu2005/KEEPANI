Política de privacidad

Última actualización: agosto 2026 · Aplica al sitio ojoalprecio.online y a la extensión de Chrome «Ojo al Precio».

Ojo al Precio es un comparador y rastreador de precios de tiendas de Nicaragua. Cuidamos tu privacidad y recolectamos el mínimo de datos necesario para funcionar. No vendemos ni compartimos tus datos con terceros con fines publicitarios.

La extensión de Chrome

Cuando visitás la página de un producto en una de las tiendas soportadas (Sinsa, Siman, Walmart, PriceSmart, El Gallo, La Curacao, RadioShack, Tropigas, Copasa), la extensión:

  • Lee la URL de esa página de producto para identificar el artículo.
  • Consulta nuestra API pública (ojoalprecio.online) para traer el historial de precios de ese producto y mostrarlo en una tarjeta.

La extensión NO recolecta datos personales, no lee otras pestañas, no registra tu navegación, no usa cookies de seguimiento ni rastrea tu actividad fuera de las páginas de producto de esas tiendas. La URL del producto se envía únicamente a nuestro servidor para obtener su historial, y no se asocia a tu identidad.

El sitio web

Si creás una cuenta para recibir alertas de precio, guardamos tu correo electrónico (para enviarte los avisos y verificar tu cuenta) y los productos que elegís seguir. Podés darte de baja de cualquier alerta desde el enlace incluido en cada correo, o eliminar tu cuenta escribiéndonos.

Usamos una medición de tráfico anónima (Google Analytics) para entender el uso general del sitio. No se usa para identificarte personalmente.

Precios y tiendas

Los precios son referenciales, tomados públicamente de cada tienda, y pueden variar. Verificá el precio final en la tienda antes de comprar. No tenemos relación comercial con las tiendas mostradas ni procesamos compras.

Tus derechos

Podés pedir acceso, corrección o eliminación de tus datos escribiéndonos a info@ojoalprecio.online.
