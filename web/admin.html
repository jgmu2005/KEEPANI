Correo (SMTP) — para enviar alertas

Con Gmail usá una contraseña de aplicación (no tu contraseña normal). El botón “Guardar ajustes” de arriba guarda también esto; luego probá con “Enviar correo de prueba”.

En Ko-fi: Settings → Webhooks & API → pegá la URL de arriba en "Webhook URL" y copiá el "Verification Token" al campo. El botón “Guardar ajustes” (arriba) guarda el token. Cuando alguien done/suscriba con el correo de su cuenta, sube de nivel solo (un-pago o suscripción).
